# Software Testing Types

## Functional Testing

Verifies that a feature works according to requirements.

Example:

* Login functionality
* Signup functionality

## Smoke Testing

A quick check to ensure critical features work.

Example:

* Application launches successfully
* User can log in

## Regression Testing

Testing existing features after changes are made.

Purpose:

* Ensure new updates do not break old functionality.

## Exploratory Testing

Testing without predefined test cases to discover defects.

Benefits:

* Finds unexpected issues
* Encourages critical thinking
